# EV内部探検

電気になって学生フォーミュラ EV の中（バッテリー → インバータ → モーター …）をめぐる、6 ステージのミニゲームです。紅陵祭2026 電気自動車同好会の展示用。

紅陵祭2026 のゲーム一覧：https://takuden-formula.github.io/koryosai2026/

```
待機（見どころのデモ・本日のランキング）→ タップ → ステージ1〜6（説明 → 体験 → ★1〜3）→ 結果（スコア・評価・本日の順位）→ 待機
```

- **インストール不要・オフラインで動く**：Windows は Chrome（または Edge）と Windows 標準の PowerShell、**Mac は Chrome（または Edge）と macOS 標準の Perl** だけで動きます。外部のライブラリやフォントは使っていません。
- **iPad・スマホでも遊べる**：ボタンは指で押しやすい大きさ。キーボードでも操作できます。
- **記録は PC のフォルダに保存**：設定で選んだフォルダの `records.csv` に1回ごとに書き足し、起動時にそこから本日のランキングと集計を読み込みます。

## 0. いちばん簡単な遊び方（インストール不要）
**https://takuden-formula.github.io/ev-inside-game/** を開くだけ。Windows・Mac・iPad・スマホのどれでも同じ。この URL を送れば誰でも遊べます。
- 記録フォルダは Chrome / Edge ならそのまま使えます。Safari（iPad など）では記録はブラウザの中に残ります（設定の「records.csv を書き出す」でファイルにできます）。
- インターネットが無い会場では下の「1. 起動」（フォルダから起動）を使います。

## 1. 起動
1. フォルダを置く（例：`OneDrive - 学校法人　拓殖大学\プログラム\ev_inside_game\`）
2. **`起動.bat` をダブルクリック** → Chrome（または Edge）でゲームが開きます
3. 本番は **`起動_全画面.bat`**：アドレスバーなしの窓で開き、**最初に画面をクリック（またはキーを押す）と全画面**になります
   - **Esc で全画面解除**、F キーでもう一度全画面
   - 終了はウィンドウを閉じてから、黒い窓を閉じる

> `index.html` を直接ダブルクリックしても遊べます（file://）。ただしこのときは記録フォルダを使えず、記録はブラウザの中だけに残ります。文化祭の本番は `.bat`（Mac は `.command`）から起動してください。

### Mac で使う
**いちばん簡単な入れ方（おすすめ）**：**ターミナル**（Launchpad で「ターミナル」と検索）を開き、次の 1 行を貼って return。デスクトップに `ev-inside-game` フォルダができて Finder で開きます。この入れ方だと下の「開発元を検証できません」の警告も出ません。
```
curl -fsSL https://raw.githubusercontent.com/Takuden-Formula/ev-inside-game/main/mac/install.sh | bash
```
同じ 1 行で最新版に入れ直せます（前の版は `ev-inside-game_old_日時` に残ります）。

**ブラウザでダウンロードするとき**：https://github.com/Takuden-Formula/ev-inside-game/archive/refs/heads/main.zip を開くと ZIP が落ちてきます。ダブルクリックで展開すると `ev-inside-game-main` フォルダが出てきます（名前は `ev-inside-game` に変えてかまいません）。この方法では `.command` の実行権限が外れることがあるので、開けないときは下の「それでも開けないとき」の方法で開いてください。

1. フォルダを好きな場所（デスクトップや書類）に置く
2. **`起動_Mac.command` をダブルクリック**（本番は **`起動_全画面_Mac.command`**）。ターミナルの窓が開き、Chrome でゲームが開きます
   - **ブラウザでダウンロードした場合、初回に「開発元を検証できないため開けません」と出たとき**：「完了」を押してから、**システム設定 → プライバシーとセキュリティ** を開き、下の方の「“起動_Mac.command”は…」の横の **「このまま開く」** を押す（パスワードを聞かれたら入力）。次からはダブルクリックで開きます
   - それでも開けないときは、**ターミナル**（アプリケーション → ユーティリティ）を開き、`bash ` と入力（最後に空白）→ `起動_Mac.command` を窓にドラッグ → return
3. 終了は Chrome の窓を閉じてから、ターミナルの窓を閉じる（「プロセスを終了しますか」は「終了」）

| ブラウザ | ゲーム | 記録フォルダ（records.csv） |
|---|---|---|
| Chrome / Edge（推奨） | ○ | ○ |
| Safari（Chrome が無いとき・iPad） | ○ | ブラウザ内に保存。設定の「records.csv を書き出す」で書き出せる |

- `.command` は Chrome → Edge → Safari の順に探して開きます
- サーバは macOS に必ず入っている Perl を使います（Python や Homebrew は不要）。ポートは 8811〜8819 の空いている番号（Windows も同じ）。いつも同じポートになるよう 8811 から順に探すので、記録フォルダの設定も毎回引き継がれます

## 2. 遊び方（受付からの流れ）
1. 待機画面では、**6 つのステージを自動でプレイする見本**が 9 秒ずつ順番に流れ、下に**本日のランキング（上位 5 位）・これまでの最高・本日の挑戦者数**が出ています。
2. お客さんが**画面のどこかをタップ（クリック、Enter）**すると始まります。「○ 番目の挑戦者さん」と受付番号が出ます。
3. 各ステージは **説明 → 「スタート」 → 体験** の順。クリアすると ★1〜3、失敗すると「もう一度」か「ここで終わる」を選べます。

   | ステージ | 体験すること | 操作 |
   |---|---|---|
   | 1. つなぐ順番 | プリチャージを使って高電圧回路を安全につなぐ | 接触器のボタン |
   | 2. セルバランス | 高いセルを放電して 8 個のセルの電圧をそろえる（60 秒） | セルをタップ／1〜8 |
   | 3. インバータ | 6 個のスイッチを切り替えてモータを回す（40 秒） | ボタン／Q W E・A S D |
   | 4. 回生ブレーキ | 回生とメカブレーキで青いゾーンに止める | ボタンを押している間／R・B |
   | 5. CAN通信 | 流れてくるメッセージを受け取る ECU に届ける | ボタン／1〜4 |
   | 6. 急速充電 | 電圧と温度を見ながら電流を上げ下げして 90% まで充電 | ボタン／↑↓ |
4. 6 ステージ目をクリアすると（途中の「ここで終わる」でも）**結果画面**：スコア・評価（S／A／B／C）・★の数・クリアしたステージ数・プレイ時間・ミス・**本日の順位**と本日のランキングが出ます。「タイトルへ」を押すか、30 秒たつと待機画面に戻ります。
5. 遊んでいる途中で**60 秒だれも触らない**と、そこまでの結果を記録して待機画面に戻ります（設定で変えられます）。

### スコアと評価
| 項目 | 内容 |
|---|---|
| スコア | ★の合計 × 100 − ミス × 20 ＋ 時間ボーナス（**全クリアのときだけ** 480 − プレイ秒。0 未満は 0） |
| プレイ時間 | ステージを遊んでいる時間の合計（説明を読んでいる時間は入れない。「もう一度」の分は入る）。難易度「ゆっくり」ではゲームの中の時間で数える |
| ミス | ステージに失敗した回数（「もう一度」で何回失敗しても数える） |
| 評価 | S：全ステージクリアで ★16 以上（EVエンジニア級！）／A：全クリアで ★12 以上／B：全クリア／C：途中まで（あと少し！） |
| ランキング | スコアの高い順。同点はプレイ時間の短い順。本日の分だけ。★0（何もクリアしていない回）は入れない |

全ステージを★3 でミスなく、約 2 分半で遊ぶと 2100 点前後です。

### 効果音
音声ファイルは使わず、Web Audio でその場で合成しています（`sound.js`）。ボタン、ステージ移動（説明が出るとき）、ステージクリア、ミス（失敗・CAN の不正解）、注意（保護停止・ショート）、CAN の正解、ゴール（全クリアのファンファーレ）。待機中の見本では鳴りません。

## 3. 設定（S キー、または右上の ⚙）
⚙ はマウスならクリック、**タッチ端末（iPad）では 1 秒長押し**で開きます（お客さんが触っても開かないように）。S キーは、ステージを遊んでいる間は使えません（ステージ3 の「V 下」と同じキーのため）。設定はブラウザに保存されます。

| 項目 | 内容 | 初期値 |
|---|---|---|
| 放置で待機画面に戻るまで | この秒数だれも触らなければ待機画面へ（遊んでいる途中なら結果を「放置で終了」として記録） | 60 秒 |
| 結果画面から待機画面に戻るまで | 結果画面を出しておく時間 | 30 秒 |
| 効果音 | ON/OFF | ON |
| 音量 | 0〜100%（動かすと試しに鳴る） | 70% |
| 難易度（ゲームの速さ） | ふつう／ゆっくり（0.8 倍）／とてもゆっくり（0.65 倍・小さい子向け）。時間制限のあるステージの時間がゆっくり進む | ふつう |
| 記録を保存するフォルダ | 「フォルダを選ぶ」で PC のフォルダを選ぶ（下の「記録」） | 未設定 |
| 集計とランキングをリセット | 本日の集計・ランキングと「これまでの最高」を 0 に戻す（records.csv は消えない。リセットより前の行は数えなくなる） | – |

### 記録（records.csv）
設定の「記録を保存するフォルダ」で選んだフォルダに `records.csv` を作り、1 回の挑戦ごとに 1 行足します（Excel で開けます）。

| 列 | 内容 |
|---|---|
| 日時・受付番号 | 受付番号は本日の通し番号（「○ 番目の挑戦者」。集計をリセットしても戻らない） |
| 結果 | 全クリア／途中で終了（「ここで終わる」）／放置で終了 |
| クリアしたステージ数・星・ミス・時間秒 | ★は 18 個満点。時間はプレイ時間（秒） |
| スコア・評価 | 上の「スコアと評価」 |
| 星の内訳・難易度 | 例「3-3-2-3-0-0」（ステージ1〜6 の★）、ふつう／ゆっくり／とてもゆっくり |

- 起動時にこのファイルを読み、**本日のランキング・挑戦人数**と**これまでの最高**を出します。別の PC で記録したファイルをこのフォルダに置けば、そのまま引き継げます
- フォルダの場所はブラウザが覚えています。ブラウザを開き直すと、**最初に画面をクリックしたとき「このフォルダの編集を許可しますか」と聞かれるので「許可」**を押してください（画面下に `記録: 許可待ち` と出ている間は保存されません）
- フォルダを選ばなくても遊べます（そのときの集計はブラウザの中だけに残ります）。ステージを 1 つも始めずに離れた人は記録しません
- 画面下に小さく `記録: OK（フォルダ名）／許可待ち／未設定 ・ 本日 ○ 人` と出ます

### キー操作
| キー | 動作 |
|---|---|
| **Enter** / スペース | 待機画面から始める・画面のボタン（スタート・次のステージへ など）を押す |
| 1〜8 | ステージ2：セルの放電 ON/OFF |
| Q W E / A S D | ステージ3：U・V・W の上／下のスイッチ |
| R / B（押している間） | ステージ4：回生ブレーキ／メカブレーキ |
| 1〜4 | ステージ5：メーター／インバータ／充電器／VCU |
| ↑ ↓ | ステージ6：電流 ±10 A |
| S | 設定（ステージを遊んでいる間は使えない） |
| F | 全画面にする |
| **Esc** | **全画面を解除**・設定を閉じる |

## 4. 困ったとき
| 症状 | 対処 |
|---|---|
| 記録が保存されない | 画面下が `記録: 許可待ち` なら画面を1回クリックして「許可」。`記録: 未設定` なら設定でフォルダを選ぶ。`記録: ブラウザ内` は index.html を直接開いたか Safari。本番は起動ファイルから開く |
| 音が出ない | 画面を1回タップ（ブラウザの決まりで、最初の操作までは音が出せない）。設定の効果音と音量を確認。**iPad は本体の消音（サイレント）を切る** |
| 設定が開けない（iPad） | 右上の ⚙ を 1 秒押し続ける |
| 全画面にならない | 画面を1回クリック、または F キー。iPhone の Safari は全画面にできません |
| 小さい子にはむずかしい | 設定の難易度を「ゆっくり」「とてもゆっくり」に |
| 起動.bat の黒い窓がすぐ閉じる・エラー | 同じフォルダの `server_log.txt` を見る。ポート 8811〜8819 がすべて使用中なら、ほかのゲームの黒い窓を閉じる |
| 途中で待機画面に戻ってしまう | 設定の「放置で待機画面に戻るまで」を長くする |

## 6. 確認状況
- **確認済み**（2026-11、Windows のヘッドレス Chrome）：
  - 待機画面の見本デモ（各ステージを 9 秒ずつ自動プレイ。時間を延ばして動かすと 6 ステージともクリアまで進む）とランキング表示、タップ／Enter で開始（タッチで始めても説明の画面が飛ばないこと）
  - 6 ステージを通して全クリア → 結果（S・2126 点・本日 1 位）、途中で失敗して「もう一度」→ 全クリア（ミス 1・2 位）、途中の「ここで終わる」→ 結果（C）
  - records.csv への書き足しと、読み込み直したときのランキング・最高点の作り直し（テストはブラウザ内の仮フォルダで実施）
  - 放置で待機画面に戻ること（遊んだ分は「放置で終了」で記録、ステージを始める前なら記録しない）、結果画面の自動で戻るカウントダウン
  - S キーと Esc での設定の開閉、⚙ の長押し（0.4 秒では開かず、1 秒で開く）
  - index.html を直接開いた（file://）ときも遊べて、記録がブラウザ内に残ること
  - iPad の画面の大きさ（1024×768）とスマホ幅（390）で、待機画面と遊んでいる画面が崩れないこと
  - `serve.ps1` がポート 8811 で起動して index.html・js が 200 で返ること、Git Bash の Perl で `mac/serve.pl` が同じく返ること、Mac のスクリプトの文法（`bash -n`・`perl -c`）
